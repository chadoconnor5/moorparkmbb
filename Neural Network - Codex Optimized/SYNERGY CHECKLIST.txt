SYNERGY CHECKLIST (what to grab each time we scout)
===================================================

Synergy needs a login, so nothing here is pulled automatically. Two parts each scout:
  A. Leaderboards: statewide, they feed the player labels for EVERY team (download as .xlsx).
  B. The opponent's own pages: screenshots, they feed that team's scouting report.
If Synergy hasn't added games since you last sent a leaderboard, skip it (same numbers).


A. LEADERBOARDS  (Junior College - Men 2026-2027, All, Player, download .xlsx)
-----------------------------------------------------------------------------
OFFENSE
  1. At Rim                          Shot Attempts -> At Rim                 -> Finisher label (LIVE)
  2. Catch and Shoot                 Catch and Shoot -> Catch and Shoot      -> shooter labels (saved, not used yet)
  3. All Jump Shots off the Dribble  Shot Attempts -> Jump Shots             -> shooter labels (saved, not used yet)
  4. All Poss + Assists              Poss + Assists -> All Poss + Assists    -> Passer / Floor general (saved, not used yet)
DEFENSE
  5. Overall                         Overall Defense -> Overall              -> Attackable / Lockdown tags (saved, not built yet)

LATER IN THE SEASON (too few players qualify early)
  - Post-Ups (Offense)  -> Interior scorer
OPTIONAL (team picture, not labels)
  - Transition, Team Defensive

TO LOAD THEM: download them (they land in Downloads), then double-click "Moorpark Synergy.bat"
(project folder; copy it to the Desktop beside Moorpark Nightly.bat). It loads every "Leaderboards ... .xlsx" in
Downloads, deletes each one it loaded, and pushes them. A file it can't read is left in Downloads and listed.

OR BY HAND (Command Prompt):
cd "%USERPROFILE%\Documents\GitHub\moorparkmbb\Neural Network - Codex Optimized"
python import_synergy_leaderboard.py "%USERPROFILE%\Downloads\Leaderboards_*.xlsx"
   (add  --delete  to remove them from Downloads once loaded)
   A re-download of the same leaderboard ("..._1.xlsx") replaces the earlier one. Pushed with the nightly.
   (Or just send them to Claude in the chat, as before.)


B. THE OPPONENT  (screenshots)
------------------------------
TEAM PAGE
  - Offense: Play Types, Shot Types
  - Defense: Play Types, Shot Types

EACH ROTATION PLAYER (7-8 players)
  Offense tab:
  - Overall (possessions, PPP, Transition / Half Court / vs Press)
  - Play Types (expand Transition and Spot Up for the breakdowns)
  - Shot Types (expand Jump Shot, Catch and Shoot: Guarded / Unguarded, At Rim)
  - Shot Distances (Jumpers): Short / Medium / Long
  - Drive Direction (Overall row expanded)  <- the only source for the Drives Left / Drives Right tag
  - P&R Ball Handler expanded, for anyone who runs pick-and-roll
  Defense tab:
  - Overall, Play Types, Shot Types

TIP: in at least one screenshot per player, include the top of the page (name, team, and which of
Offense / Defense is highlighted). Screenshots without it can't be matched to the right player or side.
