MOORPARK SCRAPE COMMANDS
========================

HOW TO USE THIS SHEET
  1. Open Command Prompt: press the Windows key, type  cmd  and press Enter.
  2. Copy ONE line below (highlight it, Ctrl+C).
  3. Click in the Command Prompt window, right-click to paste (or Ctrl+V), press Enter.
  4. Wait until it finishes (you see the  C:\...>  prompt again) before the next line.
  Lines that start with spaces are notes, not commands.
  (The latest copy of this sheet is always in the project folder: SCRAPE COMMANDS.txt)


00. EVERY NIGHT, THE ONE-CLICK WAY: double-click "Moorpark Nightly.bat" on your Desktop
--------------------------------------------------------------------------------------
   After the games are final, double-click it ONCE. It goes to the project folder, gets the latest
   code, runs the nightly scrape (screenshots first, then the site, rebuild, push) and stays open
   at the end so you can read it. Look for:  Pushed: scrape.py nightly ...
   If it says STOPPED: do NOT run it again tonight.
   Every run writes a night log (it's pushed too): scrape_state\2026-27\logs\<date>_<time>_nightly.md
   "Not complete" at the top lists each game that failed and why (what the page held, when it was read).
   One game again by its box score ID (the end of its link):  python scrape.py game 20261030_arqz --browser
   To put it on your Desktop (one time), run step 1's cd line, then:

copy "Moorpark Nightly.bat" "%USERPROFILE%\Desktop\"

   (OneDrive Desktop:)  copy "Moorpark Nightly.bat" "%USERPROFILE%\OneDrive\Desktop\"


0. THE SHORTCUT FOR EVERYTHING ELSE: double-click "Moorpark Scrape.bat" on your Desktop
--------------------------------------------------------------------------------------
   It opens Command Prompt already in the project folder and runs git pull for you,
   so you can go straight to step 2. To put it on your Desktop (one time), run step 1's
   cd line, then:

copy "Moorpark Scrape.bat" "%USERPROFILE%\Desktop\"

   (If your Desktop is in OneDrive and that says it can't find the path:)

copy "Moorpark Scrape.bat" "%USERPROFILE%\OneDrive\Desktop\"


1. WITHOUT THE SHORTCUT: go to the project folder, then get the latest code
---------------------------------------------------------------------------
   Every new Command Prompt window starts in C:\Users\Chad -- run this cd line first.
cd "C:\Users\Chad\Documents\GitHub\moorparkmbb\Neural Network - Codex Optimized"
git pull


2. EVERY NIGHT, after the games are final
-----------------------------------------
python scrape.py nightly --browser

   Reads that night's screenshot folder first, then gets only the box scores still missing from the site
   (25-45 seconds between pages, about 10-15 minutes), rebuilds everything and pushes it.
   The last line should say:  Pushed: scrape.py nightly ...
   A Chrome window opens minimized while it runs: leave it alone.
   If it says STOPPED: do NOT run it again tonight. Use screenshots instead.


3. A DIFFERENT NIGHT (change the date)
--------------------------------------
python scrape.py nightly --browser --date 2026-10-30


4. SCREENSHOTS ONLY (no website at all)
---------------------------------------
   Put screenshots in:  2026-27 Box Score Screenshots\<Month>\<MMDD>\
   Name each one:       Team MMDD      (example: Citrus 1031   -- a second shot of the same box: Citrus 1031 2)
   One screenshot per team. Short names work (Mt SAC, Sac City, SBCC, LACC...).

python read_screenshots.py
python read_screenshots.py --date 1031

   Problems are listed in CHECK.txt inside that night's folder. Fix the number in the CSV next to the
   screenshot, run it again. Add screenshots any time -- during the night or days later -- and just run it again:
   it only reads what's new. CHECK.txt always shows what's saved and what's left for that night.
   Then run the nightly (step 2) to rebuild and push. It will not ask the website for those games.


5. WHAT'S STILL MISSING (no internet used)
------------------------------------------
python scrape.py status


6. GET OLDER GAMES THAT WERE MISSING (only when needed, uses the website)
--------------------------------------------------------------------------
python scrape.py missing --browser --date 2026-10-29
python scrape.py missing --browser --team Moorpark


7. TEST WITHOUT DOING ANYTHING (shows what it would do, nothing fetched or saved)
---------------------------------------------------------------------------------
python scrape.py nightly --browser --dry-run


8. RUN BUT DON'T PUSH TO THE SITE (check things first)
------------------------------------------------------
python scrape.py nightly --browser --no-push


9. UPDATE THE LEADERBOARD ONLY (no scraping -- after a code change, or to refresh the site)
-------------------------------------------------------------------------------------------
   Step 2 (the nightly) already does all of this on its own. Use this only for a rebuild without new games.
   Rebuilds every team's stats, ratings, lineups, WAB, the leaderboard and the scouting reports from what's already
   on the PC, then pushes. Uses no internet except GitHub:

python scrape.py rebuild

   The site updates a few minutes after the push (refresh the page).


   IF A RUN SAYS "PUSH SKIPPED: pulling GitHub's changes conflicted":
   your run is saved on the PC. Get GitHub's changes keeping your box scores, then rebuild and push (one line at a time):

cd "%USERPROFILE%\Documents\GitHub\moorparkmbb\Neural Network - Codex Optimized"
git pull --no-rebase -X ours --no-edit
python scrape.py rebuild


10. ONE-TIME SETUP (already done -- only if on a new computer)
--------------------------------------------------------------
pip install playwright
python scrape.py master --from-typed


RULES TO STAY SAFE WITH THE WEBSITE
-----------------------------------
- Run the nightly ONCE a night. Never twice in a row.
- Never use --force.
- If it ever says STOPPED, wait until tomorrow and use screenshots.
